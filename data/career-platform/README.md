# 课程数据交付目录

当前 java-backend.json 是空交付结构，不是正式演示数据。成员1须提交至少30道人审Java题，覆盖基础、集合/JVM、Spring、数据库、并发。每条题记录source、许可、采集/创作时间、参考要点及人工核对记录；审阅说明列作者、审核人、日期和数据版本。企业/岗位如虚构必须is_demo=true。

测试材料在 backend/career_platform/tests/fixtures，均标记test_only，不能直接复制成真实招聘或把6题算作30题交付。未审来源保持pending，不进入正式检索；JSON导入遵循 [成员1实施文档](../../docs/implementation/01-data-catalog.md)。本目录不放用户简历、秘密或外部数据抓取缓存。
